Веб-приложение для управления технической документацией.
Стек: бэкенд Node.js (Express), фронтенд React (Vite), база данных PostgreSQL.

Скрипт start.bat сам скачивает портативные Node.js и PostgreSQL в папку
проекта (`.runtime/`) и запускает приложение. Ничего устанавливать на компьютер
не нужно.

Как запустить:
1. Дважды кликните по файлу start.bat.
2. При первом запуске дождитесь скачивания и сборки (несколько минут).
   Дальнейшие запуски — быстрые.
3. Браузер откроется автоматически на http://localhost:5000.

Как остановить:
Дважды кликните по файлу stop.bat.

Данные администратора по умолчанию:
| Поле   | Значение             |
|--------|----------------------|
| Email  | admin@library.local  |
| Пароль | Admin123             |


Папку .runtime/ можно удалить в любой момент — при следующем старте всё скачается и создастся заново.
